# Semana 1: Fundamentos de IA, Machine Learning y la Jerarquía de Datos

Bienvenido a la primera semana del curso de Machine Learning aplicado a la Ciberseguridad y el Diseño/Animación Digital.

## Objetivo de la Semana
Comprender las diferencias fundamentales entre Inteligencia Artificial, Machine Learning y Deep Learning, y aplicar la exploración inicial de datos (Pandas) bajo la óptica de la toma de decisiones de negocio, particularmente la prevención de amenazas digitales (Malware/Fraude).

## Contenido

1. **`01_Introduccion_IA_y_Jerarquia_de_Datos.ipynb`**: Cuaderno guiado por el docente donde introduciremos Python, Pandas y la carga de datos con un ejemplo estructurado (Iris Dataset simulado como Alerta de Intrusiones).
2. **`01_Laboratorio_Evaluacion.ipynb`**: Reto autónomo. Analizaremos un nuevo dataset aplicando filtros y matrices de confusión manuales para detectar la diferencia entre un falso positivo (fricción) y un falso negativo (brecha de seguridad).
3. **`01_Tarea.ipynb`**: Reto guiado con instrucciones paso a paso para consolidar los conocimientos adquiridos, aplicando iterativamente la evaluación del modelo manual.
4. **Presentación Teórica**: Diapositivas explicativas sobre la jerarquía de las necesidades de datos, representación vectorial, y la diferenciación de dominios con analogías amigables.
5. **Cuestionario**: Evaluación formativa en Moodle sobre los conceptos de la semana.

## Requisitos
- Se recomienda tener Google Colab abierto o una instalación local de Jupyter Notebook con Python 3.9+.
- Las librerías base que utilizaremos son `pandas`, `numpy`, `scikit-learn` y `matplotlib`.
